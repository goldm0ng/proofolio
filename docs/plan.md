# 취준 OS 기획안 v0.1 (요약)

전체 문서: Claude Code Artifact "취준 OS 기획안" (2026-09-07).

## 정의
내 프로젝트·경험·학습·지원 기록을 한 저장소에 쌓고, 그 위에서 지원서 초안·학습 퀴즈·모의면접을 돌리며, 바깥으로는 증빙이 붙은 공개 프로필을 내보내는 개인 커리어 OS.

## 원칙
1. 한 번 적은 것은 다시 적지 않는다 (프로젝트 → 경험 → 이력서 → 자소서 → 면접 환류).
2. AI 산출물은 항상 draft로 태어난다.
3. 기본값은 비공개 (모든 엔티티에 visibility).
4. 학습 엔진은 하나 (문제 생성 → 시도 → 채점 → 재복습).
5. 취준이 먼저 (주 10시간 상한, 수직 슬라이스).

## Phase 0 완료 기준
노션을 열지 않아도 공고 관리가 된다.
- 골격, 단일 사용자 인증, 도메인 모듈 경계, DB 스키마
- M0: 칸반 · 카드 · 체크리스트 · 공고 URL 추출 · 노션 CSV 임포트
- M1: 프로젝트 카드, 경험 CRUD
- AI 게이트웨이 최소형: 템플릿, 구조화 출력, 호출 로그

## MCP
웹앱 내부 AI는 Claude API 직접 호출. MCP는 외부 에이전트(Claude Code 등)가 내 컨텍스트를 읽는 어댑터로 Phase 4에 추가. 서비스 레이어 위에 REST 어댑터와 MCP 어댑터를 나란히.
